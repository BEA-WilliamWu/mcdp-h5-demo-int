DSP 密码加密辅助页

先在 Postman 发送 02 - Password public key，把成功响应粘贴到下面。该页面仅在本地计算，不发送网络请求，也不保存密码。

随后发送 03。function=A 首次设置，M 重设已有密码。保持 02 自动生成的 randomNumber 不变；若重新请求公钥，需要重新加密。03 是 DSP 直测，会实际保存密码，不更新 CM 的本地状态。

算法：Base64(SHA-256(password) 的原始字节) → RSA-OAEP（SHA-256，MGF1 SHA-256，空 label）→ Base64。用 Windows Edge 或 Chrome 打开本文件。
